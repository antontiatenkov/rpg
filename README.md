# 🎯 Reach Personal Goals — Геймификация Ежедневных Задач

Минималистичное веб-приложение для превращения повседневных дел и рутины в увлекательный путь достижения целей. Выполняйте ежедневные привычки и квесты, зарабатывайте опыт и золото, повышайте уровень и покупайте желанные награды в собственном магазине поощрений.

---

## 🌟 Основные возможности

1. **Журнал испытаний (Задачи)**:
   - **Ежедневные рутины (Dailies)**: Повторяются каждый день, ведут счётчик непрерывных серий (**Streak 🔥**), сбрасываются в заданное пользователем время.
   - **Разовые квесты (Quests)**: Обычные To-Do задачи, отправляющиеся в завершённые после выполнения.
   - **Градация сложности**: Легкая (+15 XP, +5 🪙), Средняя (+35 XP, +15 🪙), Сложная (+75 XP, +40 🪙).
   - Индикатор суточного прогресса выполнения рутин.

2. **RPG-прогрессия и уровни**:
   - Прогрессивная шкала опыта (каждый следующий уровень требует больше XP по сбалансированной кривой: $100 \times \text{level}^{1.35}$).
   - Звания персонажа («Новичок», «Искатель приключений», «Следопыт», «Рыцарь дисциплины» и др.).
   - Модальное окно левелапа с праздничным салютом из конфетти и бонусом золота в казну за каждый взятый уровень.

3. **Магазин наград (Rewards Shop)**:
   - Вы сами придумываете награды для себя: любимый сериал, поход в кафе, видеоигры, желанная покупка, день отдыха.
   - Установка собственной стоимости в золоте и выбор иконки/эмодзи.
   - Покупка наград за накопленные монеты и подробная история покупок.

4. **Аналитика и статистика**:
   - Дашборд с ключевыми метриками: текущий уровень, суммарный заработанный XP, общее число закрытых рутин и квестов, рекорд непрерывной серии.
   - Столбчатая диаграмма активности за последние 7 дней.

5. **Гибкие настройки и сохранность данных**:
   - **Время сброса дня**: Возможность сдвинуть суточный сброс (например, на 04:00 для полуночников).
   - **Оформление**: Переключение между Тёмной, Светлой и Системной темами.
   - **PWA**: Поддержка установки как нативного приложения на рабочий стол или мобильный телефон с офлайн-доступом.
   - **Резервное копирование**: Экспорт всей базы в единый JSON-файл и лёгкое восстановление на любом устройстве.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
После запуска откройте в браузере локальный адрес (обычно `http://localhost:5173`).

### 3. Запуск тестов
```bash
npm run test
```

### 4. Сборка для продакшена
```bash
npm run build
```
Готовая статическая сборка и Service Worker будут созданы в директории `dist/`.

Для предварительного просмотра собранного приложения:
```bash
npm run preview
```
